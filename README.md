# TODO

ブラウザだけで動くシンプルな TODO アプリです。ビルドや依存パッケージは不要です。

## 使い方

`index.html` をブラウザで開くだけです。

```sh
open index.html
```

## 機能

- タスクの追加(Enter または「追加」ボタン)
- 完了/未完了の切り替え、すべて完了にする
- タスク名の編集(ダブルクリックまたは ✎ ボタン、Enter で保存 / Esc でキャンセル、空にすると削除)
- タスクの削除、完了済みの一括削除
- 「すべて / 未完了 / 完了済み」での絞り込み(URL の `#/active` などで保持)
- `localStorage` への自動保存(別タブでの変更も反映)
- ダークモード対応、キーボード操作・スクリーンリーダー対応

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `style.css` | スタイル(ライト/ダーク) |
| `app.js` | 状態管理・描画・イベント処理 |
